Mozilla Taiwan 的 RD 們正致力於開發 Firefox OS，在專案開發的過程中，享受著把 bug 一一吃掉的小成就，也常有出乎意料的小插曲伴隨著我們。

某天早上，我依照慣例地更新自己的 code base ， build 完刷到手機上正準備來試試時，卻發現螢幕是一片黑，什麼畫面也沒有…正當我為此煩惱著不支該如何是好時，轉身問問身旁的同事們是否也有遇到相同的情況，一位同事眉開眼笑的說：「很好阿～這樣我們才有 bug 可以解！」，其他同事們也紛紛開始討論起可能的原因，甚至有人已經開始用 gdb 及 trace log 準備將這隻惱人的 bug 擒拿到手。在這裡， bug 是很搶手的。常聽到同事在電腦前懊悔：「早知道昨天就把它 (bug)  take 下來了…」，原來是昨天看到幾個有興趣的 bug ，開始找 root cause 及可能的解法，此時再回頭去看，已經有人迅速上完 patch 了！

在這裡，除了咖啡及零食之外，冰箱裡還有提供牛奶、飲料及冰棒給大家選用，更貼心的是，每天都會準備下午茶點心及水果放在吧台讓大家隨時補充能量。有著如此幸福的環境，也難怪會有「 Mozilla 20 」的傳說（來 Mozilla 會增加 20 磅?!）。另外，每月也都會舉辦生日會，準備蛋糕及飲料替當月的壽星們一起慶生。然而，在某次慶生會前，才突然發現原來當月沒有壽星，正當大家都在笑怎麼會這麼巧的同時，有兩人不約而同地開始算起「四十人，卻沒有某個月份出生的人」這個事件發生的機率究竟有多低。還有一次，為了不打擾到旁邊會議室裡面試的進行，大家紛紛壓低音量，用氣音來演唱生日快樂歌為壽星們獻上祝福。

一個大型專案的開發過程，必定有苦有澀，幸好總有這些美麗的小插曲伴隨著我們一起前進。
