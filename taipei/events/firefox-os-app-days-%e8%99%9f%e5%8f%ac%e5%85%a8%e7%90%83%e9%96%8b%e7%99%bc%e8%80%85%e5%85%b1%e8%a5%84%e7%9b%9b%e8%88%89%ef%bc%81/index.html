Firefox OS App Days 號召全球開發者共襄盛舉！

地圖加載中...
Mozilla Space
信義路五段 106 號 4F A-1 - 信義區
Details
25.032329 121.56742199999997

活動時間
日期 2013/01/04 - 2013/01/26

地點
Mozilla Space

 

眾所期待的 Firefox OS App Days 來了！想成為首批入駐 Firefox Marketplace 的 App 開發好手嗎？Firefox App Days 將由 Firefox OS 前端開發工程師團隊親自帶領開發、測試與提交 App 至 Marketplace，這是你參與 Firefox OS 與 Firefox Marketplace 的最好機會，大膽秀出你的作品，Firefox App Days 歡迎您報名！

只要您自認是個信手捻來的網頁程式設計師、網站開發者，或您平日就對 HTML5, JavaScript 和 CSS 技術有所鑽研， 都是最適合來參加 Firefox App OS Day 的好手！

在 Firefox App Days 當天，我們將教你如何利用行動 Web APIs 打造行動 Web App、並透過桌機版的 Firefox OS 模擬器來測試你所開發的行動 App。 您可以在這為期一整天的活動中，立即動手打造 Firefox OS 的 App，並上傳到 Firefox Marketplace 供全世界下載！

報名資格：

  • 具備網站開發基礎，或HTML5 開發經驗，或已有 iOS/Android 應用程式的開發者/團隊
  • 備個人網站作品與儲存空間為佳
  • 此活動採遴選制，將依個人提交的提案內容進行篩選。

活動細節：

  • 時間： 2013/1/26 9:00~19:30
  • 地點：Mozilla Space
  • 報名頁面
  • 活動首

活動議程：

  • 9:00am – 9:30am: 報到
  • 9:30am – 9:45am: 開場
  • 9:50am – 10:50am: 認識 Firefox OS & Apps Marketplace
  • 11:00am – 12:00pm: 認識 Firefox OS 模擬器, Web APIs, 開發者工具, Web App 範本
  • 12:00 – 13:00pm: 午餐時間
  • 13:00 – 17:00pm: 現場開發實作
  • 17:00pm -18:00pm: 成果展示
  • 18:00pm – 18:30pm: 票選及頒獎
  • 18:30pm – 20:00pm: 晚餐 VS 交流

參加獎項：

  • 第一名 Firefox 紀念悠遊卡 (儲值 10,000 元)
  • 第二名 Firefox 紀念悠遊卡 (儲值 5,000 元)
  • 第三名 Firefox 紀念悠遊卡 (儲值 2,000元)
  • 成果發表獎 Firefox 紀念悠遊卡 (空卡)

參加獎：

  • Firefox OS Apps Day 開發紀念 潮T
  • Firefox OS Apps Day 開發紀念小徽章
  • Firefox OS Apps Day 開發紀念貼紙

開發相關文件：

  • Introduction to Firefox OS
  • Firefox OS Docs
  • Firefox Apps Docs
  • Firefox Marketplace Developer Hub
  • Firefox OS Simulator

注意事項：

  • 報名者歡迎組隊參加，每隊 1~3 人為限
  • 活動當天請攜帶個人電腦（Linux, Mac 或 Windows … 等開發環境皆可）
  • 現場備有延長線供租借、無線網路環境
  • 報名者若自備網域名稱、個人空間者為佳
