隨著智慧型手機的普及，App (Application，應用程式) 已幾乎與我們的日常生活到了密不可分的地步。除了在手機中載入各式好玩好用的 App，你可曾想過自己編寫一個? 本門課程將帶領大家熟悉 Firefox OS 及 Web App，除了讓你認識 Firefox OS 、了解 Web 可以做什麼、什麼是 Web App，還將帶你實際動手編寫 App。從理論到實作，狐狐工作坊一次帶你完整體驗！

 

時間：8/31 (六) 14:00-16:00
地點：Mozilla Space
對象：現任或曾任 Firefox 校園大使，或校園大使之同學、朋友皆歡迎參與
想認識 Firefox 校園大使? 歡迎來信至 fxca.tw@gmail.com，我們將主動與你聯絡
備註：請自備電腦

軟體工程師 曾增仁 Evan Tseng

高中開始經營自己的網站，還不知道什麼是程式語言，卻不小心在 try and error 的過程中開始寫起了 Perl。從此，似乎就跟 Web 結下了不解之緣。目前在 Mozilla 玩 Firefox OS，負責前端界面與應用程式的開發。
