隨著智慧型手機的普及，App (Application，應用程式) 已幾乎與我們的日常生活到了密不可分的地步。除了在手機中載入各式好玩好用的 App，你可曾想過自己編寫一個? 本門課程將帶領大家熟悉 Firefox OS 及 Web App，除了讓你認識 Firefox OS 、了解 Web 可以做什麼、什麼是 Web App，還將帶你實際動手編寫 App。從理論到實作，狐狐工作坊一次帶你完整體驗！

時間：8/31 (六) 14:00-16:00

地點：Mozilla Space
