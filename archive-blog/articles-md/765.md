Mozilla Taiwan 協同台灣當地社群，於2012年7月29 在華山1914藝文中心盛大舉辦「夏日的 Web 樂園」(Summer Code Party)。活動採預約報名和現場開放制，在華山半開放式集會空間的特性下，除了預約報名的參加者外，當天也成功吸引到很多年輕/家庭一同共襄盛舉！看到小小朋友們在各攤位前認真的學習，努力在 Web 上留下足跡，只能說真是太可愛啦！這場成功的Web 園遊會，感謝台灣一同參與的在地社群，以及當天參與活動的現場嘉賓，讓我們朝更美好的網路環境大步前進！

[![](../assets/765/wp-content/uploads/P1050768-768x1024.jpg)](https://blog.mozilla.com.tw/?attachment_id=766#main)

Firefox 旗海飄揚，為「夏日的 Web 樂園」揭開序幕！

[![](../assets/765/wp-content/uploads/P1050743-768x1024.jpg)](https://blog.mozilla.com.tw/?attachment_id=767#main)

「夏日的 Web 樂園」氣球拱門歡迎您！

[![](../assets/765/wp-content/uploads/圖片2.jpg)](https://blog.mozilla.com.tw/?attachment_id=768#main)

Mozilla Taiwan 帶使用者線上製作父親節卡片，表達滿滿心意！

[![](../assets/765/wp-content/uploads/圖片3.jpg)](https://blog.mozilla.com.tw/?attachment_id=769#main)

「海洋大學網路發展協會（IND）」以「海上活動的影片」為底，讓參與者在影片上加上注意事項、步驟等註記並發佈

[![](../assets/765/wp-content/uploads/P1050846-1024x768.jpg)](https://blog.mozilla.com.tw/?attachment_id=770#main)

「MozTW」利用 Mozilla Thimble 讓參與者在網頁上以轉貼連結的方式，分享自己喜歡的影片，並發佈為網頁

[![](../assets/765/wp-content/uploads/P1050763-1024x768.jpg)](https://blog.mozilla.com.tw/?attachment_id=771#main)

「胖卡」利用 Google 的「搜尋故事」工具，讓參與者製作一段記錄搜尋過程的影片並發佈

[![](../assets/765/wp-content/uploads/P1050864-1024x768.jpg)](https://blog.mozilla.com.tw/?attachment_id=772#main)

「大同」利用網路工具做簡報，簡報的題目是「台灣景點介紹」

[![](../assets/765/wp-content/uploads/P1050868-1024x768.jpg)](https://blog.mozilla.com.tw/?attachment_id=773#main)

「Wordpress」：利用 WordPress 撰寫超簡易入門版的部落格

[![](../assets/765/wp-content/uploads/P1050889-1024x768.jpg)](https://blog.mozilla.com.tw/?attachment_id=774#main)

有趣的遊戲攤位，人氣紅不讓！

[![](../assets/765/wp-content/uploads/14.jpg)](https://blog.mozilla.com.tw/posts/765/%e3%80%8c%e5%a4%8f%e6%97%a5%e7%9a%84web-%e6%a8%82%e5%9c%92%e3%80%8d%e7%b2%be%e5%bd%a9%e8%8a%b1%e7%b5%ae%e5%9b%9e%e9%a1%a7/1-5)

闖關成功集滿六格，手拿徽章搶當網頁達人，oh yea！

[![](../assets/765/wp-content/uploads/P1050911-1024x768.jpg)](https://blog.mozilla.com.tw/?attachment_id=776#main)

Mozilla Taiwan在台灣的首次「夏日的 Web 樂園」完滿成功，期待下次再見喔！
