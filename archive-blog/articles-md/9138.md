自 9 月 1 日起，Firefox 每夜更新版 (Nightly) 即開始透過 OpenVR API 實驗性的支援「HTC Vive」頭戴式裝置。接下來幾週內，我們將陸續宣佈其他硬體支援的消息，包含 HTC Vive 控制器、Oculus Touch 控制器，以及 OSVR 頭戴式裝置。Firefox 亦將透過 OSVR API 於 Mac 與 Linux 系統中支援 WebVR。

![Image Credit: Christin Gilbert](https://blog.mozilla.com.tw/wp-content/uploads/1rppPzXIHehdGoJH6LKSIrg-1024x749.jpeg)
Image Credit: Christin Gilbert

HTC Vive 本身即具備「Lighthouse」追蹤系統，可在一般房間大小的空間中追蹤 VR 頭戴式裝置的方向與位置。玩家只要進入 WebVR 網站就能自在的四處行走。

目前 HTC Vive 支援功能仍在實驗中，稍晚亦將[另行支援](https://bugzilla.mozilla.org/show_bug.cgi?id=1299926)其控制器。若想儘早嘗鮮，可開啟 Firefox Nightly 並根據以下步驟啟用之：

- 建議先[重新整理 Firefox](https://support.mozilla.org/en-US/kb/refresh-firefox-reset-add-ons-and-settings) 以原始設定開始。因應早期 WebVR 版本所進行的某些調整，可能會在目前的 Nightly 版本中發生問題。

- 到 OpenVR GitHub repository 下載 openvr_api . dll 的 1.02 版本。如果你使用的是 64 位元的 Firefox 瀏覽器，就[下載 64 位元版本](https://github.com/ValveSoftware/openvr/raw/master/bin/win64/openvr_api.dll)；不然就請[下載 32 位元版本](https://github.com/ValveSoftware/openvr/raw/master/bin/win32/openvr_api.dll)。我們推薦 WebVR 應搭配使用 Firefox 的 64 位元版本。

- 將 openvr_api . dll 檔案儲存在 Firefox 使用者可輕鬆找到的地方。舉例來說，你可建立如「c:\openvr」路徑，並把 dll 檔案放在裡面。

- 在 Firefox Nightly 的網址列中鍵入「about:config」。

- 將「dom.vr.openvr.enabled」的值更改為「true」。

- 將「gfx.vr.openvr-runtime」的值，更改為 openvr_api . dll 的完整下載路徑，例如「c:\openvr\openvr_api.dll」。

- 重新啟動 Firefox Nightly。

接著要測試是否成功，可先試著執行 [WebVR 1.0 範例](https://webvr.info/samples/)，或到如 [SketchFab](https://sketchfab.com/) 這類可支援整個房間 WebVR 效果的網站。如果你想打造自己的 WebVR 網站，可參閱 [A-Frame](https://aframe.io/)、[three.js](https://threejs.org/)、[WebVR 1.0 Spec](https://w3c.github.io/webvr/) 獲得進一步資訊。
