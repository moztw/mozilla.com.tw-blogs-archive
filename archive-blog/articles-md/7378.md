### 拖曳元素、主控台歷史記錄，還有更多

Firefox 39 現提供多項新或提升過後的功能，並修正了多個錯誤。立刻更新自己的[開發者 (Developer)](https://www.mozilla.org/en-US/firefox/channel/#developer) 或[每夜更新 (Nightly)](https://nightly.mozilla.org/) 版本並體驗之！

#### 檢測器 (Inspector)

在[檢測器 (Inspector)](https://developer.mozilla.org/en-US/docs/Tools/Page_Inspector) 上，只要[拖曳](https://developer.mozilla.org/en-US/docs/Tools/Page_Inspector/How_to/Examine_and_edit_HTML#Drag_and_drop)即可搬移元素。用滑鼠按著任一元素不放，接著就能拖曳到你想要的位置。此功能是由 Mahdi Dibaiee 所貢獻。

早在 [Firefox 33](https://hacks.mozilla.org/2014/07/event-listeners-popup-media-sidebar-cubic-bezier-editor-more-firefox-developer-tools-episode-33/) 時，就已經將工具提示功能加到「規則 (Rule)」的檢視畫面上，以編輯 CSS 動畫的貝茲曲線 (Bézier curve)。而到 Firefox 39 的開發者版本上，我們又大幅強化了工具提示的使用者經驗，新增多個標準曲線以利使用者立刻嘗試，也讓整個介面更為美觀。此項強化功能是由 John Giannakos 所貢獻。

[![cubic](https://blog.mozilla.com.tw/wp-content/uploads/cubic-1024x658.gif)](https://hacks.mozilla.org/files/2015/04/cubic.gif)

而從[開發者版本 37](https://blog.mozilla.com.tw/posts/7021/) 起所導入的 CSS 動畫面板，現更加入了時間軸功能。你可回播＼快轉動畫，並設定其目前時間。

#### 主控台 (Console)

之前只要關閉開發者工具的主控台，則[主控台 (Console)](https://developer.mozilla.org/en-US/docs/Tools/Web_Console) 的歷史記錄也就全部遺失。現在[主控台](https://developer.mozilla.org/en-US/docs/Tools/Web_Console)的歷史記錄將可跨工作階段 (Session) 而保留。不論是在其他分頁或重新啟動 Firefox，你最近輸入的指令都會保留到下次開啟工具箱為止。此外，我們也新增了clearHistory 指令，可重設已儲存的指令清單。

新增 $_ 成為[主控台](https://developer.mozilla.org/en-US/docs/Tools/Web_Console)中的最新執行結果。舉例來說，如果你執行了表示式而並未將結果儲存為變數，則可透過 $_ 而迅速取得最新結果。

現在也格式化了結構類似陣列的物件，使其就如同[主控台](https://developer.mozilla.org/en-US/docs/Tools/Web_Console)輸出中的陣列一般。這樣可讓此類物件如同真正的陣列，以更輕鬆的追蹤並檢測之。此功能是由 Johan K. Jensen 所貢獻。

![pseudo-array](https://blog.mozilla.com.tw/wp-content/uploads/pseudo-array.png)

#### WebIDE 與行動裝置

現亦加入了 Firefox OS 的 WiFi 除錯功能。現在不需 USB 連接線，[WebIDE](https://developer.mozilla.org/en-US/docs/Tools/WebIDE) 亦可透過區域 WiFi 網路而連上 Firefox OS 裝置。請期待後續專文進一步討論此功能。

[WebIDE](https://developer.mozilla.org/en-US/docs/Tools/WebIDE) 新支援了 Cordova 架構的專案。如果你正以 Cordova 撰寫行動 App，則[WebIDE](https://developer.mozilla.org/en-US/docs/Tools/WebIDE) 就會自行為裝置建立所能支援的專案，再不需額外設定。

#### 其他更新

- 變更屬性時，只會重新整理 [Markup View](https://developer.mozilla.org/en-US/docs/Tools/Page_Inspector/How_to/Examine_and_edit_HTML) 中所變更的屬性，而不會擴及整個元素。

- [Canvas 除錯器](https://hacks.mozilla.org/2014/03/introducing-the-canvas-debugger-in-firefox-developer-tools/)現可支援動畫的 setTimeout 。

- [Box model 的 Inline 強調功能](https://blog.mozilla.com.tw/posts/7351/)。

- 按下快捷鍵「Cmd-Opt-Shit-I」或「Ctrl-Alt-Shift-I」，即可開啟[瀏覽器的工具箱](https://developer.mozilla.org/en-US/docs/Tools/Browser_Toolbox)。

- [網路監測器 (Network Monitor)](https://developer.mozilla.org/en-US/docs/Tools/Network_Monitor) 現可顯示遠端伺服器的 IP 位址與通訊埠。

- 在[檢測器](https://developer.mozilla.org/en-US/docs/Tools/Page_Inspector)中強調元素時，現可用鍵盤方向鍵的「左鍵」強調目前元素的母元素。若按下「右鍵」，則可 1). 強調其第一子元素，2). 或沒有子元素的情況下，強調其緊鄰元素，3). 或在沒有緊鄰元素的情況下，強調樹狀圖中的下個節點。只要某一元素及其母元素佔據畫面上的相同空間，只用滑鼠就很難選擇其中的元素。這時此功能就特別有用。

若需要更完整的清單，可參閱 Firefox 39 開發期間所[解掉的全部 200 個錯誤](https://mzl.la/1GiJGQm)。
