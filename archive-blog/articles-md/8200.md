Mozilla 以推動 Web 的開放、創新、機會為己身使命，因此不僅打造如 Firefox 的產品，也努力開發可強化 Web 生態系統的技術。我們希望 Web 能完整發揮潛能，並隨著使用者與開發者的互助經驗一同茁壯。因此包含 Service Workers 與其他技術的實驗，都是要啟發如 Progressive Web App 的新設計模式，這也是 Web App 故事的關鍵下一章節。

![service_webapps](https://blog.mozilla.com.tw/wp-content/uploads/service_webapps.png)
圖片來源：http://www.bonsit.nl/

在新技術擴充 Web 的規模，並讓更多開發者能夠從自己的 App 獲利之後，Web App 即在過去幾年中迅速成長。由 Mozilla 率先開發的 WebGL 與 asm.js 標準，以及如 WebAudio、Media Source Extensions、Fullscreen API 等，都讓開發者能提供更豐富的 Web 經驗。即便有了推播通知、離線使用、背景更新等功能，最終仍是「需求」才是整個平台普及的重要關鍵。

接下來即將釋出的 Services Workers、Web Push API、Web Manifest，都能讓 Progressive Web App 達到更敏銳、可重複交流的經驗，且在線離線均能運作。我們也正與業界的其他廠商合作，要讓不同瀏覽器都能運作這些功能，並提供給所有的 Web 使用者。

我們透過 [Firefox 開發者 (Developer) 版本](https://mozilla.com.tw/firefox/developer/)測試這些新功能，也期待收到開發者的反饋意見。你也可以了解應如何透過 [Service Worker Cookbook](https://github.com/mozilla/serviceworker-cookbook/) 利用這些功能。

Mozilla 樂於繼續解放 Web 的力量與 Web App 的潛能，要提供更有價值的使用者經驗。

### ─ Mozilla 技術長 David Bryant
