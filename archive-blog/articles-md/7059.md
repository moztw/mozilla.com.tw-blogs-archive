如果你是遊戲開發者，也看過《[Firefox OS 適用的 WebGL 與 CreateJS](https://blog.mozilla.com.tw/posts/4853)》一文，那你一定還對所提過 Canvas 設計出來的跳跳兔有印象吧？快來看看 Canvas 2D 現在又有哪些新東西了呢？

![bunny](../assets/7059/wp-content/uploads/bunny.jpg)

在 [Adobe Web 平台團隊](https://blogs.adobe.com/webplatform/)的協助之下，Firefox 及其他新款瀏覽器均已於去年內建了多項 HTML 的 Canvas 2D 新功能。而 MDN 上有關 [Canvas 2D 的相關說明文章](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API)也大幅更新，以確實反應出目前 Canvas 標準與瀏覽器的建構實例狀態。就先來看看有哪些新功能，又可如何協助你強化 Canvas 圖形與遊戲內容。

#### Path2D 物件

新的 [Path2D](https://developer.mozilla.org/en-US/docs/Web/API/Path2D) API (從 Firefox 31 起可用) 可儲存路徑，亦即能簡化 Canvas 繪圖碼並達到更快的執行速度。而[建構子 (Constructor)](https://developer.mozilla.org/en-US/docs/Web/API/Path2D.Path2D) 則有 3 種方式可建立 Path2D 物件：



		
		

new Path2D();     // empty path object
new Path2D(path); // copy from another path
new Path2D(d);    // path from from SVG path data

第三個版本會將 [SVG 路徑資料](https://developer.mozilla.org/en-US/docs/Web/SVG/Tutorial/Paths)納入建構，且特別方便好用。你現在也可重複使用自己 SVG 路徑，直接在 Canvas 描繪相同的輪廓：



		
		

var p = new Path2D("M10 10 h 80 v 80 h -80 Z");
			
				
					
				
					1
				
						var p = new Path2D("M10 10 h 80 v 80 h -80 Z");
					
				
			
		

在建構空白的路徑物件時，則可使用一般常見的[路徑函式](https://developer.mozilla.org/en-US/docs/Web/API/Path2D#Methods)，就像在 [CanvasRenderingContext2D](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D) 裡的使用方式。



		
		

// create a circle
var circle = new Path2D();
circle.arc(50, 50, 50, 0, 2 * Math.PI);
// stroke the circle onto the context ctx
ctx.stroke(circle);

為了要實際在 Canvas 上繪製路徑，現已更新多組內容的 API，可傳入 Path2D 路徑：

- [ctx.fill(path)](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.fill)

- [ctx.stroke(path)](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.stroke)

- [ctx.clip(path)](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.clip)

- [ctx.isPointInPath(path)](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.isPointInPath)

- [ctx.isPointInStroke(path)](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.isPointInStroke)

#### 點擊區域 (Hit regions)

從 Firefox 32 開始就支援實驗性的「[點擊區域](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Hit_regions_and_accessibility#Hit_regions)」功能。你必須先將 canvas.hitregions.enabled 設定為 true 才能測試。如果滑鼠游標處於特定區域，而不須手動檢查其座標 (這樣真的很難檢查複雜的外型)，就能透過點擊區域輕鬆偵測。而 Hit Region API 很簡單：

- [CanvasRenderingContext2D.addHitRegion()](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.addHitRegion)可將點擊區域新增到 Canvas。

- [CanvasRenderingContext2D.removeHitRegion()](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.removeHitRegion)透過特定的 id ，將點擊區域從 Canvas 移除。

- [CanvasRenderingContext2D.clearHitRegions()](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.clearHitRegions)移除 Canvas 上的所有點擊區域。

addHitRegion 函式同樣可將點擊區域添加至現有路徑或 Path2D 路徑上。另可透過 [region](https://developer.mozilla.org/en-US/docs/Web/API/MouseEvent.region) 屬性擴充 [MouseEvent](https://developer.mozilla.org/en-US/docs/Web/API/MouseEvent) 介面，檢查滑鼠游標是否點擊到該區域。

可實際參閱 [MDN 上的範例程式碼](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.addHitRegion#Using_the_addHitRegion_method) (並至少要啟用 Firefox 與 Chrome 中的設定)。

#### 焦點環 (Focus rings)

在 Firefox 32 中的 [drawFocusIfNeeded(element)](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.drawFocusIfNeeded) 屬性，同樣不需切換設定就能使用。只要其 <canvas></canvas> 元素內部既有的應變 (Fallback) 元素取得焦點，此 API 就能讓你在 Canvas 上繪製焦點環。在應變元素取得焦點 (例如按「Tab」切換到有 Canvas 的頁面)，則 Canvas 上該元素焦點環以指出目前的焦點。

#### CSS/SVG 濾鏡已可用於 Canvas

同樣必須完成設定 (canvas.filters.enabled)，且尚未納入最新的 Canvas 規格 (未來就會加入)，但 Firefox 35 已支援了 [Canvas 繪圖內容上的濾鏡 (Filter)](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.filter)。其語法即與 [CSS 的濾鏡屬性](https://developer.mozilla.org/en-US/docs/Web/CSS/filter)相同。

#### 其他

- 現已建構 [alpha](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement.getContext)[內容屬性](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement.getContext) (Firefox 30)。不透明的 Canvas 則可[加快速度](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas)！

- 現可[添增形變資訊 (Transformation) 到樣版 (Pattern)](https://developer.mozilla.org/en-US/docs/Web/API/CanvasPattern.setTransform) (Firefox 33)。

- 現已新增 [ctx.resetTransform()](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D.resetTransform) ，可重設形變資訊 (Firefox 36)。

- 敬請期待！最新 Canvas 規格另提供新的 API，且[現在](https://code.google.com/p/chromium/issues/detail?id=281529)正[著手將之建構](https://bugzilla.mozilla.org/show_bug.cgi?id=1119470)於瀏覽器之中。
