12月 28 2012

接續：關於 Mozilla 開發者社群網站，你不能不知道的十件事！（PART 1）

我們特別整理 10 項開發者必知事項，幫助開發者快速瞭解 MDN (開發者社群網站)，立馬上手之 5 至 10 項：

5. 最豐富好用的 JavaScript 參考資料。

“MDN 內含豐富又參考價值高的 JavaScript 文件，這些資源為開發者提供便利、條理化又深具參考價值的 JavaScript 文件，當開發者需尋找 JavaScript 相關資料時，甚至不需到處翻閱就可立馬找到。”– jQuery 核心開發人員

6. 開發者發掘廣泛新知的好地方。

MDN 由社群中的開發者、撰寫技術文的好手來共同維護，在數以千計的參考文件中涵蓋眾多內容，例如：HTML5、 JavaScript、 CSS、 Node.JS 等等。同時，對行動裝置開發者而言，MDN 也提供了很多參考文件，例如：如何打造 HTML5 行動 Apps 或是撰寫行動附加元件入門，以及瞭解地理定位 Apps 。

7. 任何人都可以在 Wiki 中總輯或新增檔案，你只需建立新帳號就能馬上使用。在使用過程中，毋須擔心權限以及錯誤訊息。就另一方面來說，如果你有心加入本網站的維護工作，認識／瞭解 MDN 社群想必能提供你更多的協助，誠摯歡迎您，隨時為你解答。

8. 最豐富的社群 Demo 資料：MDN在 2011 年為開發者加進 Demo Studio，目前已有超過 500 個 Demo 而且數量不斷攀升中，這個公共的地方讓開發者不單能彼此分享，也能小小炫耀一下自己寫出的程式碼。

9. 每月 Dev Derby 挑戰：針對開發者每月釋出的 Dev Derby 挑戰，從離線模式到“不使用 JavaScript” (2012年最受歡迎的Derby挑戰，共有 71 人入圍)，由專家們選出最終獲勝者。

10. 全新 HTML wiki 在 2012 年 8 月上線——這意味著開發者，不需從頭再學習一門新的程式語言來編輯和撰寫文件。這個平臺是開源且基於 Django，開發者可以從 Github至wiki 增加新的特性和功能。同時，嶄新的 HTML5  WordPress 外掛程式也緊接上線，開發者可以將自己的部落格連結到 MDN。

原文參考：https://hacks.mozilla.org/2012/12/ten-things-developers-should-know-about-the-mozilla-developer-network-mdn/
