初登場！台客艾瑞克報到！

大家好！我是愛笑愛開槓愛看棒球愛打網球愛寫程式而且最愛台丸的謀智台客──艾瑞克。

初次見面，請多指教。m(_._)m

今年一月，我成為 Mozilla 台灣的一員，其實沒想到自己會這麼快就進外商工作，以前常聽人說「某某某進外商工作了耶」，感覺那位某某某就是很有經驗的樣子，但我仍然未達而立之年（謎之聲：好像也相去不遠），就能夠到國際級的公司來見見世面，真的是很難得的一次機會。

在加入 Mozilla 以前，我從來沒有參與過任何的 Open Source 專案開發或是討論，所以到職當天我也是跟 Gecko 的原始碼初次見面。大概就在我看 code 看了幾天之後，有一天我實在忍不住了，抓住本公司的前輩 Thinker 大神就問：「到底程式碼裡面為什麼有一堆用『 NS 』開頭的變數跟巨集？」

這個問題困擾我好久，你可以想像我在看 NS_WARNING、NS_OK、nsrunnable 這些名詞的時候都自動把前兩個字略過的樣子。聽完之後，Thinker 看著我大笑，說：「NS 就是 Netscape 啊！」

這當然是令人發噱的一個插曲，Gecko 原本就是由 Netscape 時代開始開發的，只是我程式碼看昏了頭，完全沒有想到其中的關聯。這也讓我想起二月底到巴黎出差，和總部的工程師一起工作時，坐我對面的是一位講話風趣，年約 3x 的褐髮帥哥 Jonas。和他請教幾個技術問題之後就發現這傢伙真是不簡單，對整體架構非常了解，對程式碼的解說也很到位，我心想他可能已經參與開發 Gecko 有一段時間了。

後來才知道，這位仁兄 — Jonas Sicking，是 Mozilla 的重要人物，也是我們 WebAPI 團隊的頭頭，他在 1999 年就開始加入 Gecko 的開發…那時可還是 Netscape 的時代咧。

想看 Jonas Sicking 真面目嗎？

你說，能夠和這些大人物肩併肩的一起工作，是不是很令人開心呢！:)
