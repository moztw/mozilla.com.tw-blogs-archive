可供 Windows、Mac 和 Linux 使用者下載和測試的全新 [Firefox Beta](https://www.mozilla.org/firefox/beta/)版本現已開放使用。新功能加入原生 PDF 文件閱讀器，使用者不需安裝額外的外掛程式，就能獲得快速、安全的瀏覽體驗。

[![](../assets/1762/wp-content/uploads/11-16-00-4f8fe6.jpg)](https://blog.mozilla.com.tw/wp-content/uploads/11-16-00-4f8fe6.jpg)

同時，Firefox Beta 版本支援開發者，在桌機環境下測試 Firefox for Android 和 Firefox OS 中的行動 Web 應用。開啟遠端除錯器 (remote debugging)，請到 devtools.debugger.remote-enabled 為 true 即可。

更多資訊：

- 下載 [Windows、Mac 或 Linux 版 Firefox Beta](https://www.mozilla.org/firefox/beta/)

- [Firefox Beta 桌機版本資訊與技術細節](https://www.mozilla.org/firefox/19.0beta/releasenotes/)
