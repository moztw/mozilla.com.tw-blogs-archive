所有工具都源自於「如果有了這東西，我就能做得更快、更好、更輕鬆」的概念。Firefox 開發者工具就是根據這類想法而誕生，而且其中許多功能也都來自於和你一樣的 Web 開發者。

我們透過 [UserVoice 討論區](https://ffdevtools.uservoice.com/)蒐集這些想法，並讓大家票選出其開發的優先順序。

去年四月，[@hopefulcyborg](https://twitter.com/hopefulcyborg) 就提出應該要能「[Connect Firefox Developer Tools to [Insert Browser Here]](https://ffdevtools.uservoice.com/forums/246087-firefox-developer-tools-ideas/suggestions/5789823-connect-firefox-developer-tools-to-insert-browser)」。之後我們在十一月發表了 [Firefox 開發者版本 (Developer)](https://www.mozilla.org/firefox/developer/)，其內即提供該功能的預備版本，可透過 Firefox 桌面版直接對 Chrome 與 Safari (是的，甚至可用於行動裝置) 進行除錯，而此即所謂的「[Valence](https://developer.mozilla.org/docs/Tools/Valence)」。

不見得一定要多麼宏大或創新，才能算得上是好的想法與概念；重點是能更有效率的協助大家完成手上任務。以下列功能為例，都是直接取自於 UserVoice 上的反饋意見：

- 在 Firefox 39 的檢測器 (Inspector) 中，只要[拖曳 DOM 節點即可重新排序](https://ffdevtools.uservoice.com/forums/246087-firefox-developer-tools-ideas/suggestions/6050930-drag-drop-reordering-of-dom-nodes-like-in-chrome)。

- 從 Firefox 38 開始，主控台 (Console) 即可顯示[更多有用的 CORS 錯誤](https://ffdevtools.uservoice.com/forums/246087-firefox-developer-tools-ideas/suggestions/6455233-display-what-is-wrong-with-my-cors-headers)並[區隔 XHR](https://ffdevtools.uservoice.com/forums/246087-firefox-developer-tools-ideas/suggestions/5871371-log-ajax-request-response-in-the-web-console)。

- 我們為 Firefox 37 [改變了檢測器的顯示顏色](https://ffdevtools.uservoice.com/forums/246087-firefox-developer-tools-ideas/suggestions/6065330-more-obvious-colors-for-indicating-padding-and-mar)，讓色彩辨識有困難的人也能更易於使用。

- 我們為 Firefox 34 新增 [Web 儲存空間](https://ffdevtools.uservoice.com/forums/246087-firefox-developer-tools-ideas/suggestions/5707193-i-need-a-better-insight-into-appcache-and-offline)的專屬檢驗面板。

- 在 Firefox 31 時，我們將「[滴管 (Eyedropper)](https://ffdevtools.uservoice.com/forums/246087-firefox-developer-tools-ideas/suggestions/5896448-color-picker-and-tools)」色彩選擇器整合至樣式檢測器之中。

![eyedropper](https://blog.mozilla.com.tw/wp-content/uploads/eyedropper1.png)

某些功能可能看來沒多麼重要，但這些概念都造就了更好用、更有效率的開發者工具。這也是 Mozilla 的初衷：我們為你打造 Firefox，也要你知道我們仍虛心聆聽大家的想法。如果你對 Firefox 開發者工具有任何建議，歡迎[到 UserVoice 告訴我們](https://ffdevtools.uservoice.com/)。如果你還沒想到任何意見，也能投票告訴我們相關建議的急迫性。相關意見都會讓負責的人看到，並協助我們打造出更好的工具給大家。

如果你想進一步參與工具的開發，我們也很樂意協助大家[加入貢獻的行列](https://wiki.mozilla.org/DevTools/GetInvolved)。畢竟 Mozilla 本就是以開放源碼為基礎，要與社群一同提升屬於所有人的網際網路。

這裡有適合你使用的工具。[努力讓工具變得更好吧！](https://ffdevtools.uservoice.com/)
